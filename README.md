# Drilly P

Browser game prototype for the OpenAI × Tokyo AI 100-Hour Game Challenge, Track 1.
The planned game is a dungeon-building rivalry against an AI opponent. This
baseline contains the Convex + React starter; gameplay is still to come.

## Requirements

- Node.js **24.14.0**, pinned in `.nvmrc` and used by CI.
- npm (included with Node.js); use the committed `package-lock.json`.
- A Convex account with access to the team's Convex project to run the backend.

## Install and start

```sh
git clone git@github.com:twentyone212121/drilly-p.git
cd drilly-p
npm ci
npm run dev
```
